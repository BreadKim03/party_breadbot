1. 서비스

2. 사용자 책임

  • 선택하는 랭크와 포지션 정보를 정확하게 입력해 주세요. 랭크는 사용자가 직접 입력하며 봇은 Riot Games 계정이나 전적을 확인하지 않습니다.
