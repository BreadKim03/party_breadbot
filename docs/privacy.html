1. 수집·저장하는 정보

봇은 파티 모집과 참가 처리를 위해 다음 정보를 SQLite 데이터베이스에 저장합니다.

정보이용 목적
Discord 사용자 ID, 서버 ID, 채널 ID, 공고 메시지 ID방장·참가자를 구분하고 공고를 찾아 관리
게임 모드, 선택한 포지션, 사용자가 선택한 랭크모집 공고 표시와 파티 규칙 확인
참가 시각, 모집 상태, 공고 생성 시각참가자 목록과 모집 중·마감 상태 유지

봇은 일반 채팅 메시지를 읽어 수집하지 않으며, Riot Games 계정이나 전적을 조회하지 않습니다. 랭크 정보는 사용자가 직접 입력합니다.

2. 공개되는 정보

모집 공고에 참여하면 선택한 포지션과 랭크, Discord 표시 이름이 해당 공고가 게시된 Discord 채널의 이용자에게 보입니다. Discord는 플랫폼 운영을 위해 상호작용과 메시지를 자체 정책에 따라 처리합니다.

3. 저장 위치와 제공

봇 데이터베이스는 운영자가 봇을 실행하는 호스팅 환경에 저장됩니다. 운영자는 봇 기능 제공 외의 목적으로 저장 정보를 판매하지 않습니다. 봇과 Discord 간의 명령·메시지 처리는 Discord 플랫폼을 통해 이루어집니다.

이 정책 사이트는 GitHub Pages로 호스팅될 수 있습니다. GitHub는 사이트 방문자의 IP 주소를 보안 목적으로 기록할 수 있다고 안내합니다. 자세한 내용은 GitHub 개인정보 처리방침을 확인해 주세요.

4. 보관 기간과 삭제

모집 및 참가 정보는 공고 관리에 필요한 동안 데이터베이스에 보관됩니다. 방장이 `/모집취소`를 실행하면 해당 공고와 참가자 레코드가 함께 삭제됩니다. 마감된 공고 데이터는 현재 자동 만료되지 않으며, 데이터베이스에서 운영자가 삭제할 때까지 남을 수 있습니다.

자신의 정보 삭제를 요청하려면 아래 운영자 연락처로 Discord 사용자 ID와 공고 정보를 보내 주세요. 민감한 정보는 공개 GitHub 이슈에 올리지 마세요.

5. 보호와 처리 위탁

운영자는 데이터베이스 파일과 봇 토큰에 대한 접근을 제한해야 합니다. 봇 호스팅 제공자는 실행 환경과 백업 설정에 따라 데이터를 처리할 수 있습니다. 실제 호스팅 제공자와 백업 정책은 운영 환경에 따라 달라지므로 게시 전에 이 내용을 확인해야 합니다.
